# Практическая работа №1. Первичный анализ датасета tips

**ФИО:** Тоголокова Айназик

## Датасет

Используется учебный датасет `tips`, содержащий информацию о сумме счёта, чаевых, поле посетителя, статусе курения, дне недели, времени приёма пищи и размере группы.

## Цель работы

Настроить окружение Python, загрузить датасет и выполнить первичный анализ данных.

## Выполненные действия

- Настроено виртуальное окружение Python `venv`.
- Загружен датасет и просмотрены первые строки.
- Определены размер таблицы и типы данных.
- Проверены пропущенные значения.
- Рассчитаны базовые статистики числовых признаков.
- Построена гистограмма распределения суммы счёта.
- Построена столбчатая диаграмма количества наблюдений по дням недели.
- Построена диаграмма рассеяния суммы счёта и чаевых.
- Сформулированы наблюдения по результатам анализа.

## Основные результаты

- Размер датасета: 244 строки и 7 столбцов.
- Числовые признаки: `total_bill`, `tip`, `size`.
- Категориальные признаки: `sex`, `smoker`, `day`, `time`.
- Пропущенные значения в представленных столбцах отсутствуют.
- Средняя сумма счёта составляет около 19.79, средние чаевые — около 3.00.

## Наблюдения

1. Наибольшее количество наблюдений приходится на субботу — 87, наименьшее — на пятницу — 19.
2. В датасете представлены разные категории посетителей и условия посещения, что позволяет сравнивать группы между собой.
3. Между суммой счёта и чаевыми наблюдается положительная связь: при увеличении суммы счёта чаевые в целом имеют тенденцию увеличиваться.

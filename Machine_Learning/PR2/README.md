# Практическая работа №2. Разведочный анализ данных (EDA)

**ФИО:** Тоголокова Айназик

## Датасет

В работе используется датасет College Student Placement Factors Dataset.

Датасет содержит информацию о студентах и факторах, связанных с их трудоустройством.

## Цель работы

Провести разведочный анализ данных (EDA), изучить типы признаков, распределения, выбросы, категориальные признаки, корреляции и дисбаланс целевой переменной.

## Выполненный анализ

- общий осмотр данных;
- классификация признаков;
- анализ распределений числовых признаков;
- выявление выбросов с помощью boxplot и критерия IQR;
- анализ категориальных признаков;
- проверка редких категорий;
- построение корреляционной матрицы;
- анализ наиболее коррелирующей пары с помощью scatter plot;
- анализ дисбаланса целевой переменной `Placement`;
- формирование списка проблем данных.

## Основные результаты

В датасете 10 000 наблюдений и 10 признаков.

Были обнаружены потенциальные выбросы в признаке `IQ`.

Наиболее сильная корреляция обнаружена между `Prev_Sem_Result` и `CGPA` и составляет 0.98.

Целевая переменная `Placement` несбалансирована: 83.41% студентов имеют значение `No`, а 16.59% — `Yes`.

## Вывод

Проведённый EDA позволил выявить основные особенности и потенциальные проблемы данных, которые необходимо учитывать при дальнейшей подготовке данных и построении модели машинного обучения.

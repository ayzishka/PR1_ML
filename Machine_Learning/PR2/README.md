# Практическая работа №2. Разведочный анализ данных (EDA)

**ФИО:** Тоголокова Айназик

## 1. Датасет

В работе используется датасет College Student Placement Factors Dataset, содержащий информацию о студентах и факторах, связанных с их трудоустройством.

Датасет включает 10 000 наблюдений и 10 признаков.

## 2. Цель работы

Провести разведочный анализ данных (Exploratory Data Analysis, EDA), изучить структуру и качество данных, распределения признаков, потенциальные выбросы, категориальные признаки, корреляции и баланс целевой переменной.

## 3. Выполненный анализ

- Первичный просмотр данных и определение размера таблицы.
- Проверка типов данных и пропущенных значений.
- Расчёт описательной статистики.
- Анализ распределений числовых признаков с помощью гистограмм.
- Поиск потенциальных выбросов с помощью boxplot и критерия IQR.
- Анализ категориальных признаков и редких категорий.
- Построение корреляционной матрицы.
- Анализ связи между наиболее коррелирующими признаками с помощью scatter plot.
- Анализ распределения целевой переменной `Placement`.
- Формирование списка обнаруженных проблем данных и возможных дальнейших действий.

## 4. Основные результаты

- В датасете 10 000 строк и 10 столбцов.
- Пропущенные значения не обнаружены.
- Обнаружено 61 потенциальное выбросное значение в признаке `IQ` по критерию IQR.
- Наиболее сильная корреляция наблюдается между `Prev_Sem_Result` и `CGPA` и составляет 0.98.
- Целевая переменная `Placement` несбалансирована: 83.41% наблюдений относятся к `No`, а 16.59% — к `Yes`.
- Признак `College_ID` содержит 100 различных категорий.

## 5. Обнаруженные проблемы и дальнейшие действия

1. **Потенциальные выбросы в `IQ`.** Проверить, являются ли эти значения ошибками или реальными наблюдениями. Не удалять их автоматически.
2. **Высокая корреляция `Prev_Sem_Result` и `CGPA`.** Проверить, не содержат ли признаки избыточную информацию.
3. **Дисбаланс `Placement`.** При построении модели учитывать соотношение классов и выбирать подходящие метрики оценки.
4. **Высокая кардинальность `College_ID`.** Выбрать подходящий способ кодирования категориального признака.
5. **Категориальные признаки.** При подготовке данных преобразовать необходимые категориальные признаки в подходящий для модели формат.
6. **Отсутствие пропусков.** Пропуски не обнаружены, однако это не исключает других проблем качества данных.
7. **Потенциальные выбросы требуют проверки.** Перед дальнейшим анализом оценить их влияние и обоснованность возможной обработки.

## 6. Вывод

Разведочный анализ позволил изучить структуру и распределения данных, выявить потенциальные выбросы, сильную корреляцию между двумя признаками и дисбаланс целевой переменной. Полученные результаты помогут выбрать подходящие способы подготовки данных перед построением модели машинного обучения.

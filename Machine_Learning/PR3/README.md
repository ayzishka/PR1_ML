## 1. Цель работы

Собрать Pipeline для автоматической предобработки данных, объединить несколько этапов преобразования и избежать утечки информации из тестовой выборки в обучающую.

## 2. Датасет

Для работы использован датасет Telco Customer Churn, содержащий информацию о клиентах телекоммуникационной компании.

Исходный датасет содержит 7043 строки и 21 столбец. Целевая переменная — `Churn`, которая показывает, отказался ли клиент от услуг компании.

Столбец `customerID` был исключён из признаков, поскольку он является идентификатором клиента. После этого осталось 19 признаков для предобработки.

## 3. Выполненные действия

1. Загрузила датасет с помощью `pandas`.
2. Изучила структуру данных и типы столбцов с помощью `df.head()` и `df.info()`.
3. Преобразовала `TotalCharges` в числовой формат с помощью `pd.to_numeric()`.
4. Проверила пропущенные значения и обнаружила 11 пропусков в `TotalCharges`.
5. Разделила признаки и целевую переменную: `X` и `y`.
6. Разделила данные на обучающую и тестовую выборки в соотношении 80/20 с помощью `train_test_split()`.
7. Выделила числовые и категориальные признаки.
8. Создала отдельные Pipeline для обработки числовых и категориальных признаков.
9. Объединила преобразования с помощью `ColumnTransformer`.
10. Создала общий Pipeline предобработки.
11. Обучила Pipeline только на обучающей выборке.
12. Применила обученный Pipeline к обучающей и тестовой выборкам.
13. Проверила размеры полученных данных и количество оставшихся пропусков.

## 4. Использованные методы

### Числовые признаки

Для числовых признаков использовала:

- `SimpleImputer(strategy="median")` — заполняет пропущенные значения медианой, рассчитанной по обучающим данным.
- `StandardScaler()` — масштабирует числовые признаки, чтобы привести их к сопоставимому масштабу.

### Категориальные признаки

Для категориальных признаков использовала:

- `SimpleImputer(strategy="most_frequent")` — заполняет пропуски наиболее часто встречающимся значением.
- `OneHotEncoder(handle_unknown="ignore")` — преобразует категории в числовые столбцы. Параметр `handle_unknown="ignore"` позволяет обрабатывать категории, которые не встречались при обучении кодировщика.

### Объединение преобразований

`ColumnTransformer` применяет разные преобразования к числовым и категориальным признакам.

`Pipeline` объединяет этапы обработки в единую последовательность, которую можно обучить и затем использовать для преобразования данных.

## 5. Результаты работы

До обработки:

- Train: 5634 строки и 19 признаков.
- Test: 1409 строк и 19 признаков.

После обработки:

- Train: 5634 строки и 45 признаков.
- Test: 1409 строк и 45 признаков.

Количество признаков увеличилось с 19 до 45 благодаря One-Hot Encoding. Количество строк при обработке не изменилось.

В исходных данных было обнаружено 11 пропусков в `TotalCharges`. В обучающей выборке находилось 10 пропусков. После применения Pipeline пропущенных значений в обработанной обучающей выборке не осталось.

## 6. Проверка на утечку данных

Разделение на обучающую и тестовую выборки было выполнено до обучения преобразований.

Pipeline обучался с помощью `pipeline.fit(X_train, y_train)`. При этом медиана для числовых признаков, наиболее частые значения категориальных признаков, параметры масштабирования и категории для кодирования определялись на обучающей выборке.

Затем к обучающей и тестовой выборкам применялся метод `pipeline.transform()`.

Таким образом, параметры предобработки не рассчитывались по тестовой выборке, что предотвращает утечку информации из тестовых данных в обучение преобразований.

## 7. Вывод

В ходе практической работы я собрала Pipeline предобработки данных на основе `Pipeline` и `ColumnTransformer`.

Числовые признаки обрабатываются заполнением пропусков медианой и масштабированием, а категориальные — заполнением наиболее частым значением и One-Hot Encoding.

После обработки обучающая и тестовая выборки имеют одинаковое количество признаков — 45. Пропуски в обработанной обучающей выборке отсутствуют.

Использование Pipeline позволяет объединить этапы предобработки и применять их последовательно, а обучение преобразований только на обучающей выборке помогает избежать утечки данных.

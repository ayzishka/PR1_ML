# Практическая работа №3. Сборка пайплайна предобработки данных

## Цель работы

Собрать Pipeline для предобработки данных и избежать утечки информации из тестовой выборки в обучающую.

## Данные

Для работы использован датасет Telco Customer Churn.

В датасете есть числовые и категориальные признаки, а также целевая переменная `Churn`.

## Что было сделано

1. Загрузила датасет и посмотрела его структуру.
2. Преобразовала `TotalCharges` в числовой формат.
3. Обнаружила пропуски в `TotalCharges`.
4. Разделила данные на train и test в соотношении 80/20.
5. Разделила признаки на числовые и категориальные.
6. Для числовых признаков использовала заполнение пропусков медианой и `StandardScaler`.
7. Для категориальных признаков использовала заполнение пропусков наиболее частым значением и `OneHotEncoder`.
8. Объединила все преобразования с помощью `ColumnTransformer`.
9. Создала общий `Pipeline`.
10. Обучила Pipeline только на train.
11. Применяла уже обученный Pipeline к test.

## Результат

До обработки:

- Train: 5634 × 19
- Test: 1409 × 19

После обработки:

- Train: 5634 × 45
- Test: 1409 × 45

Количество признаков увеличилось из-за One-Hot Encoding категориальных признаков.

## Проверка на утечку данных

Разбиение на train и test было выполнено до предобработки.

Pipeline обучался только на обучающей выборке. После этого тот же Pipeline применялся к тестовой выборке.

Таким образом, данные из test не использовались для обучения преобразований, поэтому утечки данных нет.

## Вывод

В результате я собрала полный Pipeline предобработки данных. Он автоматически обрабатывает пропуски, масштабирует числовые признаки и кодирует категориальные признаки. Train и test после обработки имеют одинаковое количество признаков.

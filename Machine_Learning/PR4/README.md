# Практическая работа №4. Регрессионная модель

**ФИО:** Тоголокова Айназик

## 1. Цель работы

Построить модель линейной регрессии, оценить качество её предсказаний, проверить мультиколлинеарность признаков и сравнить базовую модель с моделью, в которой используется меньше признаков.

## 2. Датасет

Для работы использован датасет `Auto.csv`, содержащий информацию об автомобилях.

Размер датасета — 392 строки и 9 столбцов.

**Целевая переменная:** `mpg` — расход топлива в милях на галлон. Чем выше значение `mpg`, тем экономичнее автомобиль.

Столбец `name` не использовался при обучении, поскольку содержит названия автомобилей.

Перед обучением были проверены типы данных, пропущенные значения и дубликаты. Пропущенных значений и дубликатов не обнаружено.

## 3. Подготовка данных

Данные разделены на обучающую и тестовую выборки в соотношении 80/20. Для разделения использован `random_state=42`, чтобы результаты можно было воспроизвести.

Для подготовки данных и обучения использован `Pipeline`, включающий заполнение возможных пропусков медианой (`SimpleImputer`) и модель линейной регрессии (`LinearRegression`).

## 4. Базовая модель

Для первой модели использованы все 7 числовых признаков:

- `cylinders`
- `displacement`
- `horsepower`
- `weight`
- `acceleration`
- `year`
- `origin`

Результаты на тестовой выборке:

| Метрика | Значение |
|---|---:|
| MAE | 2.420 mpg |
| RMSE | 3.273 mpg |
| R² | 0.790 |

Средняя абсолютная ошибка MAE составляет примерно 2.42 mpg. RMSE равна 3.273 mpg и сильнее учитывает большие ошибки. Значение R² = 0.790 означает, что модель объясняет около 79% изменчивости целевой переменной на тестовой выборке.

## 5. Проверка мультиколлинеарности

Для проверки взаимосвязи между признаками построена корреляционная матрица.

Обнаружены сильные корреляции:

- `cylinders` и `displacement` — 0.95;
- `displacement` и `weight` — 0.93;
- `displacement` и `horsepower` — 0.89.

Это указывает на то, что некоторые признаки тесно связаны друг с другом и могут содержать похожую информацию.

## 6. Модель с уменьшенным количеством признаков

Для второй модели исключены `cylinders` и `displacement`. Оставлены следующие 5 признаков:

- `horsepower`
- `weight`
- `acceleration`
- `year`
- `origin`

Результаты на тестовой выборке:

| Метрика | Значение |
|---|---:|
| MAE | 2.462 mpg |
| RMSE | 3.344 mpg |
| R² | 0.781 |

Средняя абсолютная ошибка составила примерно 2.46 mpg. Значение R² равно 0.781, то есть модель объясняет около 78.1% изменчивости целевой переменной на тестовой выборке.

## 7. Сравнение моделей

Базовая модель показала немного лучшие результаты: её MAE и RMSE ниже, а R² выше.

При этом уменьшенная модель использует два признака меньше и сохраняет близкое качество предсказаний. Это показывает, что модель можно упростить с небольшой потерей точности.

## 8. Анализ остатков

Для уменьшенной модели построен график остатков, где остаток — это разница между реальным значением и предсказанием.

Точки расположены по обе стороны от нулевой линии, однако наблюдаются отдельные большие ошибки, достигающие примерно −10 и +10 mpg. Это указывает на то, что модель не всегда точно предсказывает расход топлива и может не учитывать некоторые зависимости в данных.

## 9. Итоговый вывод

В ходе работы были обучены и сравнены две модели линейной регрессии. Базовая модель на семи признаках показала немного лучшее качество на тестовой выборке: MAE = 2.420 mpg, RMSE = 3.273 mpg, R² = 0.790.

После исключения двух сильно коррелирующих признаков качество немного снизилось: MAE = 2.462 mpg, RMSE = 3.344 mpg, R² = 0.781.

Таким образом, базовая модель является лучшей по полученным метрикам. Уменьшенная модель тоже может быть полезна, поскольку она проще и показывает близкие результаты. Проверка остатков выявила отдельные большие ошибки, поэтому линейная модель не описывает все особенности данных идеально.

# Практическая работа №5. Классификатор и анализ метрик

**ФИО:** Тоголокова Айназик

## 1. Цель работы

Построить модель бинарной классификации, оценить её качество с помощью метрик и подобрать порог классификации с учётом цены ошибок.

## 2. Датасет

Использован датасет `banking.csv`, содержащий информацию о клиентах банка и результатах маркетинговых звонков.

Размер датасета — 41 188 строк и 21 столбец.

Целевая переменная — `y`:

- `0` — клиент не оформил срочный депозит;
- `1` — клиент оформил срочный депозит.

Распределение классов:

- класс `0` — 88,7%;
- класс `1` — 11,3%.

Таким образом, в данных наблюдается дисбаланс классов, поэтому для оценки модели недостаточно использовать только accuracy.

## 3. Подготовка данных

Данные разделены на обучающую и тестовую выборки в соотношении 80/20 с использованием `random_state=42` и `stratify=y`.

Обучающая выборка содержит 32 950 строк, тестовая — 8 238 строк.

Пропущенные значения в исходном датасете отсутствуют.

Для обработки числовых признаков использованы заполнение пропусков медианой и `StandardScaler`. Для категориальных признаков использованы заполнение наиболее частым значением и `OneHotEncoder`.

Все этапы предобработки и обучения объединены в `Pipeline`.

## 4. Обучение модели

Использована модель `LogisticRegression` с параметром `max_iter=1000`.

После обучения получены вероятности оформления депозита с помощью `predict_proba()`.

## 5. ROC-кривая и PR-кривая

Результаты оценки вероятностей:

| Метрика | Значение |
|---|---:|
| ROC-AUC | 0.938 |
| PR-AUC (Average Precision) | 0.599 |

ROC-AUC = 0.938 показывает, что модель хорошо различает клиентов двух классов.

PR-AUC = 0.599 характеризует качество выявления положительного класса с учётом Precision и Recall. Эта метрика особенно полезна при дисбалансе классов.

В ноутбуке построены ROC-кривая и PR-кривая.

## 6. Цена ошибок и выбор порога

Для выбора порога использовано условное допущение: пропустить потенциального вкладчика (FN) в три раза дороже, чем ошибочно отнести клиента к заинтересованным в депозите (FP).

Условная стоимость ошибок рассчитывалась по формуле:

`Стоимость = 3 × FN + FP`

Были проверены пороги от 0.05 до 0.50 с шагом 0.01. Среди проверенных значений минимальную стоимость ошибок показал порог 0.20.

Это допущение используется для учебного анализа и не является реальной финансовой оценкой банка.

## 7. Сравнение порогов

| Метрика | Порог 0.50 | Порог 0.20 |
|---|---:|---:|
| TN | 7126 | 6646 |
| FP | 184 | 664 |
| FN | 540 | 220 |
| TP | 388 | 708 |
| Precision | 0.678 | 0.516 |
| Recall | 0.418 | 0.763 |
| F1 | 0.517 | 0.616 |
| Стоимость ошибок | 1804 | 1324 |

При пороге 0.20 Recall увеличился с 0.418 до 0.763. Это означает, что модель выявляет большую долю клиентов, оформивших депозит.

Precision снизился с 0.678 до 0.516, поскольку среди предсказанных заинтересованными клиентов стало больше ложноположительных результатов.

При этом условная стоимость ошибок снизилась с 1804 до 1324 единиц, то есть примерно на 26,6%.

## 8. Матрица ошибок

Для порога 0.20 построена матрица ошибок.

- **TN = 6646:** модель правильно предсказала отсутствие депозита.
- **FP = 664:** модель предсказала оформление депозита, но клиент его не оформил.
- **FN = 220:** модель не выявила клиента, который оформил депозит.
- **TP = 708:** модель правильно предсказала оформление депозита.

## 9. Итоговый вывод

В ходе работы обучена модель логистической регрессии и проведена оценка качества бинарной классификации. ROC-AUC составил 0.938, а PR-AUC — 0.599.

Стандартный порог 0.50 был сравнен с порогом 0.20. При снижении порога увеличились Recall и F1, а условная стоимость ошибок уменьшилась с 1804 до 1324 единиц.

Для выбранного учебного сценария порог 0.20 предпочтительнее, поскольку пропуск потенциального вкладчика считается более дорогой ошибкой. При этом снижение Precision показывает, что для выявления большего количества потенциальных клиентов приходится принимать больше ложноположительных результатов.

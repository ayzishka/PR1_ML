# Практическая работа №6. Классификация текстов

**ФИО:** Тоголокова Айназик

## 1. Цель работы

Научиться очищать текстовые данные, преобразовывать текст в числовые признаки и обучать модель для классификации отзывов.

## 2. Датасет

Использован датасет с отзывами покупателей Wildberries на русском языке. Исходный файл `filtered.csv` содержит 27 248 строк и 9 столбцов.

После удаления отзывов без текста или оценки, а также нейтральных оценок, осталось 17 992 отзыва.

Целевая переменная `sentiment` содержит два класса:

- `positive` — положительный отзыв, оценка 4 или 5;
- `negative` — отрицательный отзыв, оценка 1 или 2.

После очистки текста 20 отзывов стали пустыми и были удалены. В итоге для обучения и проверки использовалось 17 972 отзыва.

## 3. Обработка текста

Для подготовки отзывов выполнены следующие действия:

1. Перевод текста в нижний регистр.
2. Удаление цифр.
3. Удаление знаков препинания.
4. Разбиение текста на отдельные слова с помощью `split()`.
5. Удаление русских стоп-слов с помощью библиотеки `nltk`.
6. Сохранение отрицаний, например «не», «ни» и «нет», поскольку они важны для смысла отзыва.

## 4. Векторизация текста

Для преобразования текстов в числовые признаки использован `TfidfVectorizer`.

Параметры векторизатора:

- `min_df = 3` — учитываются слова, встречающиеся не менее чем в трёх документах;
- `max_df = 0.9` — исключаются слова, встречающиеся более чем в 90% документов.

Данные разделены на обучающую и тестовую выборки в соотношении 80/20 с использованием `random_state=42` и `stratify`.

- Обучающая выборка — 14 377 отзывов.
- Тестовая выборка — 3 595 отзывов.
- Размер словаря — 11 039 признаков.

Векторизатор обучался только на обучающих данных с помощью `fit_transform()`. Для тестовых данных использовался `transform()`, чтобы избежать утечки информации из тестовой выборки.

## 5. Обучение модели

Использован классификатор `MultinomialNB` (наивный байесовский классификатор).

Модель обучена на TF-IDF-признаках обучающей выборки, после чего выполнены предсказания тональности тестовых отзывов.

## 6. Результаты

Основные метрики модели:

| Метрика | Отрицательные отзывы | Положительные отзывы |
|---|---:|---:|
| Precision | 0,93 | 0,86 |
| Recall | 0,27 | 1,00 |
| F1-score | 0,42 | 0,92 |

Общая Accuracy составила **86,34%**.

Модель хорошо определяет положительные отзывы, но хуже находит отрицательные. Recall отрицательного класса равен 0,27, то есть модель обнаруживает лишь около 27% всех отрицательных отзывов в тестовой выборке.

Возможная причина — дисбаланс классов: в тестовой выборке 2 943 положительных и 652 отрицательных отзыва.

## 7. Анализ ошибок

На тестовой выборке модель допустила 491 ошибку из 3 595 предсказаний.

Были рассмотрены пять примеров неправильных предсказаний. Возможные причины ошибок:

- сложные и длинные формулировки;
- наличие одновременно положительных и отрицательных слов;
- сокращения и особенности разговорного языка;
- недостаточная способность модели учитывать контекст и отрицания;
- возможное несоответствие текста отзыва выставленной оценке.

В одном из рассмотренных примеров отзыв о запахе был отнесён моделью к отрицательному классу, хотя правильный класс в датасете — положительный.

## 8. Вывод

В ходе работы были очищены текстовые данные, выполнена векторизация с помощью TF-IDF и обучена модель `MultinomialNB`.

Модель показала Accuracy 86,34% и F1-score 0,92 для положительных отзывов. Однако F1-score отрицательного класса составил 0,42, а Recall — 0,27.

Таким образом, высокая общая точность не означает, что модель одинаково хорошо распознаёт оба класса. Для улучшения выявления отрицательных отзывов можно в дальнейшем исследовать балансировку классов, другие модели классификации и настройку параметров.

# Практическая работа №6. Классификация текстов

## Цель работы

Научиться очищать текстовые данные, преобразовывать текст в числа и обучать модель для классификации отзывов.

## Датасет

Использован датасет с отзывами покупателей Wildberries на русском языке.

После удаления пустых отзывов и нейтральных оценок осталось 17 992 отзыва. Затем 20 отзывов, которые стали пустыми после очистки текста, были удалены.

В итоге для обучения и проверки использовалось 17 972 отзыва.

## Обработка текста

1. Перевод текста в нижний регистр.
2. Удаление цифр и знаков препинания.
3. Удаление стоп-слов.
4. Токенизация с помощью `split()`.
5. Сохранение отрицаний, например «не», для сохранения смысла отзывов.

## Векторизация

Для преобразования текстов в числовые признаки использован TF-IDF.

- `min_df = 3`
- `max_df = 0.9`
- Размер словаря: 11 039 признаков.

Данные разделены на обучающую часть (80%) и тестовую часть (20%). Векторизатор обучался только на обучающих данных.

## Модель

Использован классификатор Multinomial Naive Bayes (`MultinomialNB`).

## Результаты

- Accuracy: 86,34%.
- Precision для отрицательных отзывов: 0,93.
- Recall для отрицательных отзывов: 0,27.
- F1-score для отрицательных отзывов: 0,42.
- F1-score для положительных отзывов: 0,92.

Модель хорошо определяет положительные отзывы, но хуже находит отрицательные. Возможная причина — дисбаланс классов: положительных отзывов в датасете значительно больше.

## Анализ ошибок

Были рассмотрены пять неправильных предсказаний. Возможные причины ошибок: смешанный смысл отзыва, сложные формулировки, сокращения и несоответствие текста оценке покупателя.

## Вывод

В ходе работы я очистила текстовые данные, преобразовала их с помощью TF-IDF и обучила модель Naive Bayes. Модель показала точность 86,34%, но для улучшения распознавания отрицательных отзывов требуется дальнейшая настройка.

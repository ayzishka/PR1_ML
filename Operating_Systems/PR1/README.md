# Практическая работа №1. Диагностическое тестирование и знакомство с Linux

## Цель работы

В этой работе я познакомилась с Linux и основными командами терминала. Также я создала пользователя, группу и настроила права доступа к общей папке.

## Вариант B

### 1. Создание пользователя и группы

Сначала я создала группу developers.

Затем создала пользователя student2 и добавила его в группу developers.

Проверка показала:

student2 : student2 users developers

Это означает, что пользователь student2 входит в группу developers.

### 2. Создание общей папки

Я создала каталог /srv/shared.

Владельцем папки является root, а группой — developers.

Права папки:

drwxrwsr-x

Члены группы developers могут создавать и изменять файлы в этой папке. Остальные пользователи могут читать и заходить в папку, но не могут создавать или удалять файлы.

### 3. Проверка прав доступа

От имени student2 я создала файл:

/srv/shared/student2_file.txt

После этого основной пользователь попробовал удалить этот файл.

Результат:

Permission denied

Это произошло потому, что у основного пользователя нет права записи в /srv/shared.

Таким образом, настроенные права работают правильно.

### 4. Разница между su и sudo

Команда su позволяет переключиться на другого пользователя.

Например:

su - student2

После команды whoami результат:

student2

Команда sudo позволяет выполнить отдельную команду с правами администратора.

Проверка:

sudo whoami

Результат:

root

В Ubuntu прямой вход под root по умолчанию отключён. Вместо этого используется sudo, чтобы права администратора выдавались только для нужных команд.

### 5. Настройка .bashrc

В файл ~/.bashrc я добавила два alias:

alias ll='ls -la'

alias c='clear'

Также добавила переменную окружения:

export COURSE="OS"

После этого я проверила их работу.

Команда ll показывает подробный список файлов.

Команда c очищает терминал.

Команда echo $COURSE выводит:

OS

После открытия новой сессии терминала настройки также работают.

# Практическая работа №1. Первичный анализ датасета tips

**ФИО:** Тоголокова Айназик

## Датасет

В работе используется учебный датасет `tips`, содержащий информацию о счетах в ресторане, чаевых, поле посетителя, статусе курения, дне недели, времени приёма пищи и размере группы.

## Выполненные действия

В рамках практической работы были выполнены:

* настройка виртуального окружения Python;
* загрузка и первичный просмотр датасета;
* определение размера таблицы;
* определение типов данных;
* проверка пропущенных значений;
* получение базовой статистики;
* построение графика распределения суммы счета;
* построение графика количества посещений по дням недели;
* построение графика связи суммы счета и чаевых;
* формулировка наблюдений по данным.

## Выбор окружения

Для выполнения работы использовано виртуальное окружение Python `venv`, так как оно позволяет изолировать зависимости проекта от других Python-проектов.
